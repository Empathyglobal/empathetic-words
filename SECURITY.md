# Security and privacy

This release runs without accounts, a backend, secrets, or persistent player records. Do not add student names, real classroom incidents, credentials, or production data to public issues or examples.

Please report security concerns privately to the repository maintainer using GitHub's private vulnerability reporting when enabled. If unavailable, request a private reporting channel without posting exploit details or personal information.

Dependency audit results are point-in-time only. Review changes before hosting for children. Hosting access logs and device speech behavior are outside this source package's control.
